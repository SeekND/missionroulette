This is a quick project for Star Citizen
It allows you to easily create several linked missions for the game for people that have been playing too long and don't know what to do.
You can play it solo or with a friend.

It calculates the time missions would take and give you several missions based on your selection.
There's a full admin mode that allows you to add new missions/locations if you so wish.

You can access the http via https://seeknd.github.io/missionroulette
